# Инструкция по установке

## Требования

Для работы скриптов на твоем ПК должен стоять Git.

[Ссылочка](https://github.com/git-for-windows/git/releases/download/v2.54.0.windows.1/Git-2.54.0-64-bit.exe)

## Установка

1. Открой папку с модами и удали все нахрен.
2. Справа на этом сайте есть раздел "__Releases__". Там ты должен скачать `install.zip` из последнего релиза, он над "__Source code__ (zip)"
3. Внутри этого архива лежит `install.bat`, положи его в _пустую_ папку модов.
4. Запусти его двойным кликом.
5. Жди
6. Ты поймешь, когда он закончит.

### Следующий шаг

Среди модов есть несколько файлов с расширением `.bat`. Не трогай никакие кроме `update.bat`. Этот скрипт автоматически обновляет папку: подтягивает новые моды и удаляет старые.

> Рекомендую сделать ярлык на рабочем столе. ПКМ по `update.bat` > Отправить > Рабочий стол (создать ярлык)

После этого ты сможешь обновлять моды максимально быстро с рабочего стола.
